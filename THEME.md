# itsprathi profile theme

## Palette

| Token | Hex | Use |
|---|---|---|
| Background | `#070A12` | profile background / terminal base |
| Panel | `#0B1220` | cards / code panels |
| Border | `#1F2A44` | subtle edges |
| Neon cyan | `#00E5FF` | primary accent |
| Light blue | `#60A5FA` | secondary accent |
| Blue | `#38BDF8` | utility accent |
| Purple | `#8B5CF6` | secondary neon |
| Soft violet | `#A78BFA` | headings / glow |
| Magenta | `#FF5CF4` | optional anime / social accent |
| Main text | `#F8FAFC` | high contrast text |
| Muted text | `#A7B0C0` | supporting text |
| Dim text | `#64748B` | metadata |

## Visual direction

- Dark terminal / cyberpunk interface.
- Neon cyan + blue + violet.
- Japanese/pixel/arcade accents without forcing every section into the same theme.
- Use animation sparingly where GitHub supports it; use GitHub Actions for the genuinely dynamic parts.
